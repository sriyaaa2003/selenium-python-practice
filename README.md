# Selenium & Python Practice Scripts

Practice scripts for Selenium browser automation and a few basic Python programs.

## What I did
| File | What it does |
|------|--------------|
| `index.js` | Selenium WebDriver script (Node.js) that opens Google in Chrome and searches for "Selenium" |
| `exp.js` | Selenium script with four checks on Google (page title, search, results count, search box visible) that prints pass or fail for each |
| `prime.py` | prints the prime numbers in a range |
| `reg.py` | Tkinter registration form that shows the submitted details |
| `welcome.html` | simple test page |

## Tech stack
JavaScript (Node.js), Selenium WebDriver, ChromeDriver, Python, Tkinter, HTML.
